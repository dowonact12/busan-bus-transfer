## ID 체계
- 공식 다운로드 정류소ID(11자리, 예 13051 → 21130591008)와 API bstopid(9자리, 193420201)는 **다른 체계**. ARS+좌표+이름으로 매핑, 자르지 않음.
- 같은 이름 다른 ARS 확인: 안락동우체국.동해선안락역 36번 06173(bstopid 166400101) vs 43번 06708(166400102).
